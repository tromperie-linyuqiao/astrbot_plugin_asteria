长期约定与核心资料

当前新增与维护已统一到 Asteria「长期约定」。在真实完整私聊范围中维护约定、边界、偏好、个人资料、事实和当前状况，支持停用、归档、恢复及导入导出。

停用保留内容，归档可恢复；启用只是参与后续上下文筛选，不保证每轮引用，也不覆盖人格、本轮明确修正或权限。

跳转后请核对上方真实会话。不会把此页旧记录、全局或群聊归属自动复制到私人约定；没有已授权会话时，目标页会保留说明并禁用写入。

模块配置

维护 / 迁移 / 清理

先确认来源与操作范围，再执行维护。可移植档案导入会备份当前记忆库；LivingMemory 导入是否备份沿当前配置，内容修复不自动创建备份。

1. 运行预设

轻量模式关闭外部检索调用；标准模式平衡功能和成本；陪伴模式提高关系与连续性记忆预算。已有 Provider 选择不会被覆盖。

2. 运维诊断

查看检索路径、缓存命中率、模型 Token 与耗时，以及可能重复注入的记忆插件目录。

3. 可移植数据

适用于 Asteria 记忆中心导出的 UTF-8 JSONL（沿用 MemoryCompanion 格式）。包含记忆及修订、身份、关系、时间线与 ACL，不是整个 TLS 或记忆库所有表的完整备份。

文件保存在运行 Asteria 的服务器，不会自动下载到手机或电脑。导入需服务器可读取的文件，最大 64 MiB；QQChatExporter 文件请进入“历史聊天导入”。

包含与不包含的资料

v2 保留记忆的有效期、归属、状态与修订来源；不恢复活跃图谱、向量、注入日志和模型凭据。分段读取的导出也不是全库同一时刻快照。导入的同 ID 记忆发生冲突会跳过，身份、关系、时间线和 ACL 仍沿原各自写入规则，不是整库替换。

4. LivingMemory 导入

先预览来源库与可导入表，跳过派生碎片。填写的服务器路径会优先检查；不可用时原扫描仍可能找到其他旧库。选择来源不会锁定文件，完成后请核对实际来源。

5. 内容修复

用于修复早期导入后只剩旧库编号的记忆。建议先确认 LivingMemory 数据库路径，再执行修复。

6. 维护检查

修复索引、刷新统计并整理数据库状态。适合导入、清理或配置调整后手动执行一次。

7. 可回滚记忆审计

仅在配置中启用后可用。先生成证据约束的预览，再明确应用；已应用批次可回滚。

8. 危险清理

清空会先备份数据库，再删除记忆、权限规则、时间线、关系、身份、注入日志和导入批次。
